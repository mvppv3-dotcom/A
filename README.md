# AIRA 2.9.1

**دستیار آموزشی فارسی برای ویندوز | فرمان صوتی، گفتار و ابزارهای کلاس**

AIRA یک دستیار دسکتاپ فارسی با رابط راست‌چین است که برای پشتیبانی از کارهای آموزشی و روزمرهٔ کلاس طراحی شده است. این پروژه فرمان‌های فارسی را دریافت و مسیریابی می‌کند و قابلیت‌هایی برای تعامل صوتی، خلاصه‌سازی کلاس، ضبط و پردازش رسانه و اتصال اختیاری به ابزارهای آموزشی فراهم می‌کند.

## معرفی رزومه‌ای

**AIRA — دستیار هوشمند آموزشی فارسی**  
طراحی و توسعهٔ یک برنامهٔ دسکتاپ فارسی برای تعامل صوتی و خودکارسازی کارهای کلاس. پروژه از رابط PySide6، پردازش فرمان‌های فارسی، موتورهای گفتار و مدل‌های محلی، خلاصه‌سازی مرحله‌ای، ابزارهای ضبط رسانه و یکپارچه‌سازی اختیاری با تجهیزات آموزشی استفاده می‌کند.

### قابلیت‌ها

- دریافت و مسیریابی فرمان‌های فارسی، از جمله عبارت‌های محاوره‌ای
- تعامل صوتی و پشتیبانی از موتورهای تشخیص و تولید گفتار
- خلاصه‌سازی محتوای کلاس و اعتبارسنجی خروجی
- ابزارهای ضبط صدا و تصویر و پردازش رسانه
- داشبوردهای آموزشی و رابط کاربری راست‌چین
- اتصال اختیاری به ESP32 و کنترل‌های ارائه در PowerPoint
- قفل اختیاری چهره و PIN بازیابی برای ویندوز

### نکات نسخهٔ ۲٫۹٫۱

- پنجرهٔ فرمان صوتی پس از بیدارباش یا اجرای موفق فرمان: ۴ ثانیه
- زمان آغاز ضبط خلاصه‌سازی کلاس و ضبط شخصی: ۸ ثانیه
- یکسان‌سازی رقم‌های فارسی، عربی و انگلیسی برای PIN
- قفل ۱۵ دقیقه‌ای مسیر PIN پس از پنج تلاش ناموفق
- نصب موتور چهره به‌صورت اختیاری و جدا از نصب پایه

## فناوری‌ها

Python · PySide6 · NumPy · Vosk · Sherpa-ONNX · ONNX Runtime · Piper TTS · SQLite · Windows DPAPI

## وضعیت آزمون

گزارش همراه نسخه، ۹۶۶ تست موفق، ۳ تست ردشده و صفر شکست/خطا را در ماتریس ۱۰۷ ماژولی ثبت می‌کند. این ارقام از گزارش نسخه نقل شده‌اند و در این محیط مستقلاً اجرا و تأیید نشده‌اند. آزمون Windows، رابط PySide6، DPAPI، دوربین، میکروفون، PowerPoint و ESP32 فیزیکی باید روی دستگاه مقصد انجام شود.

## یادداشت امنیتی

قفل چهره فاقد تشخیص زنده‌بودن (PAD/liveness) تأییدشده است و جایگزین Windows Hello یا احراز هویت چندعاملی نیست.
